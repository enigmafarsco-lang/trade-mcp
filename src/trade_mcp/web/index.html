اتصال OpenCode به همین ابزارها

این کنسول و OpenCode هر دو به یک هسته وصل می‌شوند: OpenCode از راه MCP (stdio) و این صفحه از راه HTTP محلی. برای اینکه OpenCode هم همین ابزارها را ببیند، در فایل ~/.config/opencode/opencode.json این بلوک را داشته باش: 
{
  "mcp": {
    "servers": {
      "trade": {
        "type": "local",
        "command": ["/ABS/PATH/.venv/bin/trade-mcp", "serve"],
        "environment": {
          "TRADE_MCP_BACKEND": "file",
          "TRADE_MCP_FILES_DIR": "/media/.../MetaTrader 5/MQL5/Files"
        }
      }
    }
  }
}
سپس در OpenCode با /mcps بررسی کن که trade وصل است.
