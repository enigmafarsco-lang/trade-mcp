# Freqtrade آفلاین: وضعیت و ورودی واقعی لازم

## وضعیت صادقانه
مسیر Binance آنلاین در Colab کاربر با HTTP451 مسدود شد. دیگر اجرا/تکرار نشود.
مسیر جدید آماده شده و اعتبارسنجی/قطع شبکه با دادهٔ مصنوعی **فقط در تست واحد**
آزمایش شده است. بستهٔ واقعی BTC/USDT/مشخصات بازار در Arena نداریم؛ Freqtrade
هم در این محیط نصب نیست. **اجرای انتها‌به‌انتهای موتور آفلاین هنوز تأیید نشده**.
هیچ دادهٔ ساختگی به‌عنوان گزارش مالی عرضه نشده، هیچ نصب محلی انجام نشده است.

## کد کامل، نه وصله
- `notebooks/freqtrade_strategy001_offline_colab.ipynb`: فقط یک سلول کامل.
- `notebooks/freqtrade_strategy001_offline_colab.py`: همان کد کامل قابل کپی.
- `scripts/freqtrade_offline_worker.py`: اجرای واقعی `Backtesting.start()`.
- `scripts/pack_freqtrade_offline_bundle.py`: بسته‌بندی فایل‌های واقعی موجود؛ بدون دانلود.

**تا بستهٔ واقعی ندارید نوت‌بوک را اجرا نکنید.** ورودی، گزارش Kronos یا دادهٔ
۱۰۰۰کندلی XAUUSD نیست. دادهٔ ناقص/نامعتبر رد می‌شود؛ بازه یا بازار خودکار
عوض نمی‌شود. مسیر آفلاین مشکل نبود داده را جادویی حل نمی‌کند.

## مشخصات بسته
JSON با schema=`freqtrade-offline-bundle/v1` و دقیقاً این چهار کلید:
- schema
- provenance: exchange=binance، source (منبع مجاز واقعی بدون credential)،
  captured_at (زمان واقعی ذخیره)، ccxt_version (نسخه واقعی ذخیره‌کننده)
- market: شیء واقعی CCXT برای BTC/USDT spot شامل id/base/quote/active/contract،
  precision واقعی tick-size و limits واقعی price/amount/cost. هیچ پیش‌فرضی ساخته نمی‌شود.
- candles: دو آرایه `1m` و `5m`، هر ردیف `[epoch_seconds,open,high,low,close,volume]`.
  UTC واقعی، بازهٔ کامل 2025-12-30T00:00Z تا قبل2026-04-01T00:00Z، بدون شکاف.
  تطابق OHLCV پنج کندل1m با هر کندل5m کنترل می‌شود؛ پرکردن شکاف مجاز نیست.

برای فایل‌های **از قبل موجود و مجاز** از help بسته‌بند استفاده کنید:
`python scripts/pack_freqtrade_offline_bundle.py --help`
این ابزار به Binance وصل نمی‌شود و snapshot یا کندل تولید نمی‌کند. برای تهیه
ورودی از VPN/تغییر منطقه یا دورزدن محدودیت استفاده نکنید. منبع داده باید حق
دسترسی/استفاده مستقل و مجاز داشته باشد. فعلاً چنین بسته‌ای از کاربر دریافت نشده.
اظهار provenance، احراز اصالت مستقل نیست؛ این محدودیت صریحاً در خروجی ثبت می‌شود.
همچنین snapshot فعلی به معنی صحت قوانین محدودیت/precision در تاریخ گذشته نیست.

## موتور، بدون شبیه‌سازی جعلی
نسخه2025.10 و سورس واقعی پین‌شده Strategy001 حفظ می‌شوند. Exchange واقعی
Freqtrade با بارگذاری شبکه‌ای به‌تعویق‌افتاده ساخته، سپس بازار ذخیره‌شده به CCXT
تزریق و validate_config واقعی اجرا می‌شود؛ منطق معامله/ROI/stoploss بازنویسی
نشده است. شیء exchange از مسیر پشتیبانی‌شدهٔ `Backtesting(config, exchange=...)`
وارد موتور می‌شود. نسخه CCXT نصب‌شده باید با snapshot برابر باشد.

در کل مرحلهٔ موتور، اتصال Python socket، DNS و connect_ex ممنوع است؛ هر
تماس احتمالی به‌جای retry متوقف می‌شود. این guard جای firewall سیستم‌عامل نیست
و برای Python engine مورد اعتماد طراحی شده. این ابزار برای کد غیرقابل اعتماد
sandbox امنیتی نیست. مرحله setup ممکن است برای پکیج/سورس به PyPI/GitHub وصل شود.
هیچ بایننس، کلید حساب، سفارش، fallback یا نتیجهٔ سود جعلی وجود ندارد.

تنظیمات شبیه‌سازی همان کارمزدفرضی0.1٪ هر سمت، stake100USDT، سرمایه1000USDT است؛
این اعداد موجودی/هزینه واقعی نیستند. داده1m جای تیک و Bid/Ask و اسلیپیج واقعی
را نمی‌گیرد. final test ثابت می‌ماند؛ اجرای موفق نیز مجوز معامله نیست.
