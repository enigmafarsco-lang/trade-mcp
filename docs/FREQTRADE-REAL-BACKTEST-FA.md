در Arena اجرا نشده است.** هیچ نصب محلی، تماس صرافی یا سفارش در Arena انجام نشده.

نوت‌بوک قدیمی `freqtrade_strategy001_colab.ipynb` فقط متدهای سیگنال را اجرا

تمام وابستگی‌های انتقالی قفل نشده‌اند و بازتولید بیت‌به‌بیت تضمین نمی‌شود.

## تنها اقدام کاربر
نوت‌بوک جدید را در **runtime تازه و hosted Colab** باز کنید و Run all بزنید.
هیچ ورودی MT5، فایل XAUUSD یا API key لازم نیست. هنگام پایان، JSON و ZIP
دانلود می‌شوند. JSON خلاصه را برای بررسی بفرستید؛ ZIP حاوی خروجی موتور را
محلی نگه دارید. هشدار/خطای واقعی را گزارش کنید، نتیجه ساختگی نسازید.
اگر دسترسی Binance محدود بود توقف کنید؛ این مسیر fallback/VPN/retry ندارد.
در توقف میانهٔ اجرا، قبل از هر اجرای دوباره وضعیت سلول/خروجی بررسی شود.

## طرح از پیش تعیین‌شده
- جفت BTC/USDT، بازار نقدی Binance، داده عمومی UTC.
- دانلود 2025-12-30 تا2026-04-01 برای warm-up، استراتژی5m و جزئیات1m.
- ارزیابی 2026-01-01 تا2026-03-01؛ تست نهایی مارس2026. هیچ hyperopt انجام نمی‌شود.
- warm-up دویست کندل، سرمایهٔ فرضی1000USDT، stake100USDT، حداکثر یک پوزیشن.
- کارمزد فرضی0.1٪ هر سمت؛ ROI/stoploss خود Strategy001 حفظ می‌شود.
- دادهٔ گمشده پر نمی‌شود؛ بررسی پوشش و OHLCV پیش از بک‌تست انجام می‌شود.
- صفر معامله، زیان، و سود همگی همان‌طور از فایل واقعی موتور استخراج می‌شوند.

اعداد USDT شبیه‌سازی‌اند، نه موجودی/هزینهٔ واقعی کاربر. market_change مرجع
buy-and-hold توصیفی است، با سرمایه/میزان درگیری یکسان نیست. این آزمون نه
مومنتوم M1 است، نه XAUUSD/MT5، نه خروج نقدی−2/+2. کندل1m جای تیک و Bid/Ask
را نمی‌گیرد؛ اسلیپیج واقعی، صف سفارش و هزینهٔ بروکر طلا مدل نشده‌اند.
یک جفت و یک ماه final test شواهد کافی سودآوری نیست. نتیجهٔ final test برای
تنظیم استراتژی استفاده نشود. خروجی هیچ مجوز اجرایی/معامله‌ای صادر نمی‌کند.
