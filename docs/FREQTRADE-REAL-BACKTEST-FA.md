**وضعیت: کد آماده و تست اتصال سلول‌ها/خواندن خروجی انجام شده؛ بک‌تست واقعی
در Arena اجرا نشده است.** هیچ نصب محلی، تماس صرافی یا سفارش در Arena انجام نشده.

نوت‌بوک قدیمی `freqtrade_strategy001_colab.ipynb` فقط متدهای سیگنال را اجرا
و forward return حساب می‌کرد؛ آن را بک‌تست موتور ننامید. فایل قدیمی حفظ شده.
نوت‌بوک جدید از فرمان واقعی `freqtrade backtesting` نسخه2025.10 استفاده می‌کند.
سورس Strategy001 از commit و SHA256 قبلی، بدون تغییر، در Colab دریافت می‌شود.
وابستگی‌ها در venv جدا داخل Colab نصب و نسخه‌های نصب‌شده در خروجی ثبت می‌شوند؛
تمام وابستگی‌های انتقالی قفل نشده‌اند و بازتولید بیت‌به‌بیت تضمین نمی‌شود.

## تنها اقدام کاربر
نوت‌بوک جدید را در **runtime تازه و hosted Colab** باز کنید و Run all بزنید.
هیچ ورودی MT5، فایل XAUUSD یا API key لازم نیست. هنگام پایان، JSON و ZIP
دانلود می‌شوند. JSON خلاصه را برای بررسی بفرستید؛ ZIP حاوی خروجی موتور را
محلی نگه دارید. هشدار/خطای واقعی را گزارش کنید، نتیجه ساختگی نسازید.
اگر دسترسی Binance محدود بود توقف کنید؛ این مسیر fallback/VPN/retry ندارد.
در توقف میانهٔ اجرا، قبل از هر اجرای دوباره وضعیت سلول/خروجی بررسی شود.

## طرح از پیش تعیین‌شده
- جفت BTC/USDT، بازار نقدی Binance، داده عمومی UTC.
- دانلود 2025-12-30 تا2026-04-01 برای warm-up، استراتژی5m و جزئیات1m.
- ارزیابی 2026-01-01 تا2026-03-01؛ تست نهایی مارس2026. هیچ hyperopt انجام نمی‌شود.
- warm-up دویست کندل، سرمایهٔ فرضی1000USDT، stake100USDT، حداکثر یک پوزیشن.
- کارمزد فرضی0.1٪ هر سمت؛ ROI/stoploss خود Strategy001 حفظ می‌شود.
- دادهٔ گمشده پر نمی‌شود؛ بررسی پوشش و OHLCV پیش از بک‌تست انجام می‌شود.
- صفر معامله، زیان، و سود همگی همان‌طور از فایل واقعی موتور استخراج می‌شوند.

اعداد USDT شبیه‌سازی‌اند، نه موجودی/هزینهٔ واقعی کاربر. market_change مرجع
buy-and-hold توصیفی است، با سرمایه/میزان درگیری یکسان نیست. این آزمون نه
مومنتوم M1 است، نه XAUUSD/MT5، نه خروج نقدی−2/+2. کندل1m جای تیک و Bid/Ask
را نمی‌گیرد؛ اسلیپیج واقعی، صف سفارش و هزینهٔ بروکر طلا مدل نشده‌اند.
یک جفت و یک ماه final test شواهد کافی سودآوری نیست. نتیجهٔ final test برای
تنظیم استراتژی استفاده نشود. خروجی هیچ مجوز اجرایی/معامله‌ای صادر نمی‌کند.

## نسخهٔ کامل یک‌سلولی و اصلاح توقف‌ها
برای جلوگیری از ادامهٔ دستی پس از شکست مرحلهٔ قبلی، از
`notebooks/freqtrade_strategy001_onecell_colab.ipynb` استفاده کنید. فقط یک سلول
کد دارد و دقیقاً برابر فایل کامل `.py` است. نیازی به وصله‌کردن سلول‌های قبلی نیست.
فرمان‌ها خروجی کامل stdout/stderr را نمایش می‌دهند. پیش از دانلود و بررسی داده،
پرچم اعتبار داده پاک می‌شود؛ بدون تأیید آن، بک‌تست ممنوع است.

بررسی سورس رسمی Freqtrade نشان داد مسیر `user_data` باید از قبل موجود باشد؛
کد قبلی این پیش‌شرط را تضمین نمی‌کرد. نسخه جدید پوشه را می‌سازد و `--userdir`
را صریح می‌دهد. این یک ایراد قطعی کد بود، اما بدون stderr اجرای کاربر نمی‌توان
گفت تنها علت خطاهای قبلی همین بوده است. فایل گمشده، دادهٔ خالی یا شکاف همچنان
باعث توقف می‌شود. پوشهٔ جدید `verified-results` خروجی‌های قبلی را پاک/بازنویسی
نمی‌کند. اگر این پوشه نتیجهٔ قبلی داشته باشد، کد برای جلوگیری از اجرای تکراری
متوقف می‌شود. هیچ بک‌تست واقعی در محیط Arena ادعا نمی‌شود.

### اصلاح schema و استفاده مجدد از نصب
Freqtrade2025.10 حتی برای Telegram خاموش فیلدهای token/chat_id را اجباری
می‌داند. نسخه اصلاح‌شده هر دو را خالی نگه می‌دارد؛ هیچ توکنی لازم نیست.
بلوک ناقص api_server حذف شده؛ API به صورت پیش‌فرض خاموش است. پیش از هر تماس
صرافی، schema خود بستهٔ نصب‌شده در subprocess آفلاین بررسی می‌شود.
اگر همان نسخهٔ Freqtrade در محیط جدا نصب باشد، bootstrap و pip install
دوباره اجرا نمی‌شوند. برای این اصلاح نیازی به تغییر runtime/restart نیست.
منابع Colab و عمر session تحت کنترل این کد نیست؛ در session جدید نصب دوباره
ممکن است لازم شود. این تغییر، دسترسی Binance یا موفقیت بک‌تست را تضمین نمی‌کند.
